# Mrsingh Lawn Mowing

Demo site for kaamtasker.com/mrsingh-lawn-mowing/ — lawn mowing & gardening. Cloned from tree-safe-solutions; content from real sources only (see src/data.js).

- Logo: Real logo (green mower badge + Mrsingh / lawn mowing) from their site — transparent; dark lettering recoloured white for the dark bands; favicon from the badge
- Hero: Mixkit 47172 (Lawn mower cutting the grass in the garden), Free Stock Video License

```
npm ci && npm run build   # dist/ → public_html/kaamtasker.com/mrsingh-lawn-mowing/
```
