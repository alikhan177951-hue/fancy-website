# Jobes Mowing

Demo site for kaamtasker.com/jobes-mowing/ — lawn mowing & gardening. Cloned from tree-safe-solutions; content from real sources only (see src/data.js).

- Logo: Real logo (grass hexagon with JOBES MOWING banner) from their site — clean cutout with the banner lettering kept white
- Hero: Mixkit 7223 (Machine mowing the lawn), Free Stock Video License

```
npm ci && npm run build   # dist/ → public_html/kaamtasker.com/jobes-mowing/
```
