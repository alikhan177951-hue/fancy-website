# Dawn Of Lawn

Demo site for kaamtasker.com/dawn-of-lawn/ — lawn mowing & gardening. Cloned from tree-safe-solutions; content from real sources only (see src/data.js).

- Logo: Real logo (mower over the sun, DAWN OF LAWN) from their site — transparent; black lettering recoloured white for the dark bands; favicon from the mower
- Hero: Mixkit 47172 (Lawn mower cutting the grass in the garden), Free Stock Video License

```
npm ci && npm run build   # dist/ → public_html/kaamtasker.com/dawn-of-lawn/
```
