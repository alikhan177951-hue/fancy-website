# Lumberjohn Tree Care

Demo site for kaamtasker.com/lumberjohn-tree-care/ — tree services. Cloned from tree-safe-solutions; content from real sources only (see src/data.js).

- Logo: Real logo (pines + LUMBERJOHN / TREE CARE SERVICE) from their site, cropped transparent cutout used as a recolourable mask; favicon from the pine mark
- Hero: Mixkit 7120 (Man is sawing tree branches), Free Stock Video License

```
npm ci && npm run build   # dist/ → public_html/kaamtasker.com/lumberjohn-tree-care/
```
