# Westside Yard Care

Demo site for kaamtasker.com/westside-yard-care/ — gardening & landscaping. Cloned from tree-safe-solutions; content from real sources only (see src/data.js).

- Logo: Real logo mark (the leaf-in-a-square) from their site, recoloured white for the dark bands with the Westside Yard Care name set beside it; favicon from the mark
- Hero: Mixkit 10472 (Man mowing the lawn with a mower), Free Stock Video License

```
npm ci && npm run build   # dist/ → public_html/kaamtasker.com/westside-yard-care/
```
