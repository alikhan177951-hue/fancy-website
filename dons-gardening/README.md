# Don's Gardening

Demo site for kaamtasker.com/dons-gardening/ — lawn mowing & gardening. Cloned from tree-safe-solutions; content from real sources only (see src/data.js).

- Logo: Real logo (green grass over DON'S, 'Done right. Every time.') from their site — background keyed out to a transparent cutout; favicon from the logo
- Hero: Mixkit 10472 (Man mowing the lawn with a mower), Free Stock Video License

```
npm ci && npm run build   # dist/ → public_html/kaamtasker.com/dons-gardening/
```
