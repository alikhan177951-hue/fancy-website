# North West Mowing & Gardening

Demo site for kaamtasker.com/northwest-mowing/ — lawn mowing & gardening. Cloned from tree-safe-solutions; content from real sources only (see src/data.js).

- Logo: Real logo (green Northwest over the mowing&gardening swoosh) from their site — cut out from the white background; black lettering recoloured white for the dark bands
- Hero: Mixkit 14383 (Lawn mower on a green grass), Free Stock Video License

```
npm ci && npm run build   # dist/ → public_html/kaamtasker.com/northwest-mowing/
```
