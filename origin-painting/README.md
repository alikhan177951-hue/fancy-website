# Origin Painting

Demo site for kaamtasker.com/origin-painting/ — house & commercial painting. Cloned from tree-safe-solutions; content from real sources only (see src/data.js).

- Logo: Real logo (gold star over ORIGIN / PAINTING) from their site — transparent cutout, sits on the dark header/hero/footer/menu exactly as designed; favicon from the star
- Hero: Mixkit 36701 (Hand of a painter painting a wall with a brush), Free Stock Video License

```
npm ci && npm run build   # dist/ → public_html/kaamtasker.com/origin-painting/
```
