# Let's Roll Painting

Demo site for kaamtasker.com/lets-roll-painting/ — house painting. Cloned from tree-safe-solutions; content from real sources only (see src/data.js).

- Logo: Real logo (Let's ROLL with the colour-wheel O, PAINTING) from their Wix site — transparent cutout; on dark bands the black PAINTING is recoloured white; favicon from the colour wheel
- Hero: Mixkit 46081 (Woman painting the walls in a bright green), Free Stock Video License

```
npm ci && npm run build   # dist/ → public_html/kaamtasker.com/lets-roll-painting/
```
