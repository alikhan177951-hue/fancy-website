# Real Painters Melbourne

Demo site for kaamtasker.com/real-painters-melbourne/ — house painting. Cloned from tree-safe-solutions; content from real sources only (see src/data.js).

- Logo: Real logo (teal roller-and-roof emblem, RealPainters MELBOURNE) from their Wix site — transparent cutout; grey lettering lightened on dark bands; favicon from the emblem
- Hero: Mixkit 32537 (Painting a wall with white paint), Free Stock Video License

```
npm ci && npm run build   # dist/ → public_html/kaamtasker.com/real-painters-melbourne/
```
