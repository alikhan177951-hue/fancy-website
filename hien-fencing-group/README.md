# Hien Fencing Group

Demo site for kaamtasker.com/hien-fencing-group/ — fencing. Cloned from tree-safe-solutions; content from real sources only (see src/data.js).

- Logo: Real logo (house + blue picket fence + tree, HIEN FENCING) from their WordPress site, white plate removed to a transparent cutout; header uses the mark + matching wordmark, favicon from the mark
- Hero: Mixkit 47293 (Welder welding construction steel frames), Free Stock Video License

```
npm ci && npm run build   # dist/ → public_html/kaamtasker.com/hien-fencing-group/
```
