# LawnMate Mowing

Demo site for kaamtasker.com/lawnmate-mowing/ — lawn mowing. Cloned from tree-safe-solutions; content from real sources only (see src/data.js).

- Logo: Real logo (green leaf + LawnMate Mowing) from their site — transparent; dark green lettering recoloured white for the dark bands; favicon from the leaf
- Hero: Mixkit 7223 (Machine mowing the lawn), Free Stock Video License

```
npm ci && npm run build   # dist/ → public_html/kaamtasker.com/lawnmate-mowing/
```
