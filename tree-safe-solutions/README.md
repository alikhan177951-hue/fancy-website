# Tree Safe Solutions

Demo site for Tree Safe Solutions (Keilor East). Vite + React + Framer Motion, base `/tree-safe-solutions/`.

- `npm ci && npm run build` → `dist/` (committed)
- Deploy: upload `dist/` (incl. `.htaccess`) to `public_html/kaamtasker.com/tree-safe-solutions/`
- Hero: Mixkit 24983 chainsaw clip, scroll-scrubbed (see `public/videos/LICENSE.md`)
- Logo: vector rebuild of their own logo (`public/brand/`)
