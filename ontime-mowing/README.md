# On Time Mowing & Gardening

Demo site for kaamtasker.com/ontime-mowing/ — lawn mowing & gardening. Cloned from tree-safe-solutions; content from real sources only (see src/data.js).

- Logo: Real logo (mowing mascot over ONTIME / MOWING & GARDENING / FAST. CLEAN. RELIABLE.) from their site — cream background keyed out; green lettering lifted to white on dark; header uses the mascot
- Hero: Mixkit 47172 (Lawn mower cutting the grass in the garden), Free Stock Video License

```
npm ci && npm run build   # dist/ → public_html/kaamtasker.com/ontime-mowing/
```
